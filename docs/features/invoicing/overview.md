# Hóa đơn

Tạo và quản lý hóa đơn chuyên nghiệp cho doanh nghiệp.

## Tính năng

- **Tạo hóa đơn** với nhiều dòng sản phẩm
- **Tự động tính toán** tổng tiền, thuế
- **Theo dõi trạng thái** thanh toán
- **Xuất PDF** gửi cho khách hàng

## Trạng thái hóa đơn

| Trạng thái | Mô tả |
|------------|-------|
| **Draft** | Bản nháp, chưa gửi |
| **Pending** | Đã gửi, chờ thanh toán |
| **Paid** | Đã thanh toán |
| **Overdue** | Quá hạn thanh toán |
| **Cancelled** | Đã hủy |

## Thông tin hóa đơn

- Mã hóa đơn (tự động tạo)
- Thông tin khách hàng
- Danh sách sản phẩm/dịch vụ
- Thuế và chiết khấu
- Hạn thanh toán
