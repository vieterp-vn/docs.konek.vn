# Tạo doanh nghiệp mới

## Các bước thực hiện

1. Đăng nhập vào [konek.vn](https://konek.vn)
2. Click **Tạo doanh nghiệp** trên Dashboard
3. Điền thông tin doanh nghiệp
4. Click **Tạo** để hoàn tất

## Thông tin cần chuẩn bị

| Trường | Mô tả |
|--------|-------|
| Tên doanh nghiệp | Tên chính thức của công ty |
| Ngành nghề | Chọn từ danh sách có sẵn |
| Mô tả | Giới thiệu ngắn gọn |
| Logo | Hình ảnh đại diện (PNG, JPG) |

## Sau khi tạo

- Bạn tự động là **Owner**
- Có thể mời thành viên ngay
- Truy cập đầy đủ các tính năng
