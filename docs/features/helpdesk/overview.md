# Helpdesk

Hệ thống Helpdesk giúp bạn tiếp nhận và xử lý yêu cầu hỗ trợ từ khách hàng.

## Tính năng

- **Tạo phiếu hỗ trợ** với độ ưu tiên và phân loại
- **Phân công** phiếu cho thành viên
- **Theo dõi trạng thái** và tiến độ xử lý
- **Bình luận** trao đổi với khách hàng

## Trạng thái phiếu

| Trạng thái | Mô tả |
|------------|-------|
| **Open** | Mới tạo, chưa xử lý |
| **In Progress** | Đang xử lý |
| **Resolved** | Đã giải quyết |
| **Closed** | Đóng phiếu |

## Độ ưu tiên

| Ưu tiên | Màu | Mô tả |
|---------|-----|-------|
| **Low** | Xanh lá | Không gấp |
| **Medium** | Vàng | Bình thường |
| **High** | Cam | Cần xử lý sớm |
| **Urgent** | Đỏ | Cần xử lý ngay |
