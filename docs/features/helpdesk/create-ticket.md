# Tạo phiếu hỗ trợ

## Các bước tạo phiếu

1. Vào **Helpdesk** > **Phiếu hỗ trợ**
2. Click **Tạo phiếu mới**
3. Điền thông tin:

| Trường | Mô tả | Bắt buộc |
|--------|-------|----------|
| **Tiêu đề** | Tóm tắt vấn đề | ✅ |
| **Mô tả** | Chi tiết vấn đề | ✅ |
| **Độ ưu tiên** | Low / Medium / High / Urgent | ✅ |
| **Người phụ trách** | Chọn thành viên xử lý | ❌ |

4. Click **Tạo phiếu**

## Mẹo viết phiếu tốt

- **Tiêu đề rõ ràng**: "Không thể đăng nhập" thay vì "Lỗi"
- **Mô tả chi tiết**: Các bước tái hiện lỗi
- **Đính kèm ảnh chụp màn hình** nếu cần

## Đính kèm tệp

1. Khi tạo hoặc sửa phiếu
2. Kéo thả tệp vào vùng đính kèm
3. Hỗ trợ: PNG, JPG, PDF, DOC (tối đa 10MB)
