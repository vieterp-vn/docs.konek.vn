# Module Kế toán

Module Kế toán giúp quản lý công nợ khách hàng và xử lý thanh toán.

![Payments](/img/screenshots/wholesale/accounting-payments.png)

## Tính năng chính

### Quản lý công nợ
- Theo dõi công nợ theo khách hàng
- Công nợ theo hóa đơn
- Cảnh báo quá hạn

### Thanh toán
- Ghi nhận thanh toán
- Thanh toán nhiều hóa đơn cùng lúc
- Đối soát thanh toán

## Quy trình thanh toán

```
Đơn hàng → Hóa đơn → Công nợ → Thanh toán → Tất toán
    ↓          ↓         ↓          ↓          ↓
 Xác nhận   Xuất HĐ   Ghi nợ    Thu tiền   Xong
```

## Phương thức thanh toán

| Phương thức | Mô tả |
|-------------|-------|
| Tiền mặt | Thanh toán trực tiếp |
| Chuyển khoản | Thanh toán qua ngân hàng |
| Công nợ | Ghi nợ, thanh toán sau |
