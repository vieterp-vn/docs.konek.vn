# Tạo khách hàng mới

Hướng dẫn tạo và quản lý thông tin khách hàng.

## Tạo khách hàng

1. Vào **Khách hàng** từ menu chính
2. Click nút **Tạo mới**
3. Điền thông tin khách hàng:

### Thông tin cơ bản

```
Tên khách hàng: [Tên công ty hoặc cá nhân]
Mã khách hàng: [Tự động tạo hoặc nhập thủ công]
Loại: [Cá nhân / Công ty]
```

### Thông tin liên hệ

```
Điện thoại: [Số điện thoại]
Email: [Địa chỉ email]
Website: [Website công ty]
```

### Địa chỉ

```
Địa chỉ: [Số nhà, đường]
Phường/Xã: [Chọn từ danh sách]
Quận/Huyện: [Chọn từ danh sách]
Tỉnh/Thành phố: [Chọn từ danh sách]
```

## Thêm nhiều địa chỉ

Mỗi khách hàng có thể có nhiều địa chỉ giao hàng:

1. Trong form khách hàng, vào tab **Địa chỉ**
2. Click **Thêm địa chỉ**
3. Chọn loại địa chỉ:
   - Địa chỉ giao hàng
   - Địa chỉ hóa đơn
   - Địa chỉ khác

## Import khách hàng từ Excel

Để import nhiều khách hàng cùng lúc:

1. Tải template Excel từ hệ thống
2. Điền thông tin khách hàng theo mẫu
3. Upload file và xác nhận import

:::tip Mẹo
Sử dụng mã khách hàng có quy tắc (ví dụ: KH001, KH002...) để dễ quản lý và tìm kiếm.
:::
