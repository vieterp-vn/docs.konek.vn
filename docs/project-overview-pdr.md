# Project Overview - Product Development Requirements

## Product Vision

Trang tài liệu hướng dẫn sử dụng Konek, giúp khách hàng tự học và giải quyết vấn đề một cách hiệu quả.

## Goals

1. **Giảm tải hỗ trợ**: Khách hàng tự tìm câu trả lời trước khi liên hệ support
2. **Onboarding nhanh**: Người dùng mới làm quen với platform trong 10 phút
3. **SEO**: Tăng khả năng tìm kiếm qua Google

## Target Audience

- Chủ doanh nghiệp sử dụng Konek
- Quản trị viên (Admin) quản lý team
- Nhân viên sử dụng các tính năng hàng ngày

## Tech Stack

| Component | Technology |
|-----------|------------|
| Framework | Docusaurus 3.x |
| Language | TypeScript |
| Styling | CSS Modules + Infima |
| Hosting | Vercel (recommended) |
| i18n | Vietnamese (default) + English |

## Content Structure

### Diataxis Framework

- **Tutorials**: Hướng dẫn từng bước cho người mới
- **How-to**: Giải quyết task cụ thể
- **Reference**: Tra cứu thông tin
- **Explanation**: Giải thích khái niệm

### Documentation Sections

1. **Getting Started** - Onboarding (3 pages)
2. **Features** - 5 modules × 3 pages = 15 pages
3. **Support** - FAQ, Troubleshooting, Contact (3 pages)

**Total: 21 pages (MVP)**

## Success Metrics

| Metric | Target |
|--------|--------|
| Page load time | < 2s |
| Lighthouse score | > 90 |
| Search visibility | Top 10 cho "konek hướng dẫn" |
| Support ticket reduction | -20% sau 3 tháng |
